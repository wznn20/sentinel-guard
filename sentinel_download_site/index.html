核心能力
六重防线，全面守护
从实时防御到事后取证，Sentinel 覆盖安全运营全链路。每一个模块都可独立运行，也可协同作战。

纯防御

专注防御，无攻击模块。不提供任何攻击性功能，确保 Sentinel 永远不会被武器化。每一行代码只为保护而生。

自带AI

接入你自己的 AI 模型。支持 OpenAI、Anthropic、DeepSeek 等 100+ 提供商。基于上下文理解做出威胁判断，而非死规则匹配。

自动取证

检测到威胁后自动采集日志快照、流量片段等完整证据链，一键导出结构化证据包，加速事件响应与溯源。

流量分析

实时抓包 + 特征匹配，检测 SQL注入/XSS/SSRF/C2通信/数据外泄。纯检测不拦截，先看清再行动。

多平台告警

支持 QQ、飞书、Discord、Telegram、Slack 等主流平台。告警分级推送，Critical 事件即时触达。

一键部署

一条命令完成安装，自动检测操作系统、安装依赖、注册系统服务。支持 Linux / macOS / Windows / Docker。

系统架构
轻量高效的分层设计
Sentinel 采用四层架构：数据采集层、AI 分析引擎、响应执行层、管理面板。每层独立运行，资源占用约 128MB~512MB。

开始使用
全平台支持，一键部署
Sentinel 支持 macOS · Windows · Linux · Docker，选择你的平台开始安装。
Linux / macOS
# Sentinel 安装 — 全平台
# 一条命令，无需 Git，自动安装依赖
pip install https://github.com/wznn20/sentinel-guard/releases/download/v0.2.0/sentinel_guard-0.2.0-py3-none-any.whl

# 或从 GitHub 安装（需 Git）
pip install git+https://github.com/wznn20/sentinel-guard.git@v0.2.0
sentinel setup
📋 安装说明
  • 需要 Python >= 3.10
  • 自动安装依赖
  • 支持 systemd / launchd 服务注册
  • 安装后运行 sentinel setup 完成配置
