KX Agent

Release hub for the local-first orchestration runtime.

Install from the latest stable wheel, upgrade without cloning the repo, and launch the control room with consistent `kx` commands.

Install

Stable latest release, no git required.
pip install --upgrade https://github.com/wznn20/sentinel-guard/releases/latest/download/kx_agent-latest-py3-none-any.whl kx setup kx chat

Upgrade

`kx upgrade` now detects packaged installs and upgrades safely.
kx upgrade kx status --json

Control Room

Operator dashboard and app server.
kx dashboard kx app
  • Sessions, approvals, delegations, memory tree
  • Live task orchestration and operator actions
  • Static frontend assets packaged with the runtime
